## 🚀 Getting Started

```bash
# 1. Install dependencies

npm install

# 2. Start backend (Terminal 1)
cd backend
uvicorn app.main:app --reload

# 3. Start frontend (Terminal 2)
cd frontend
npm run dev

# 4. Open browser
http://localhost:3000

# 5. Login as manager
# 6. Navigate to Manager Dashboard
# 7. Explore all features!
```
